# 2sc

Личный аудиоплеер для Android: воспроизведение по ссылке, в фоне и на заблокированном экране.

**[Скачать последнюю версию →](../../releases/latest)**

## Требования

- Android 10 (API 29) и новее.

## Установка

Приложение распространяется сайдлоадом, без Google Play.

1. Откройте **[последний релиз](../../releases/latest)** и скачайте `2sc-<версия>.apk`.
2. Разрешите установку из неизвестных источников для браузера или файлового менеджера.
3. Установите APK. Обновления ставятся поверх: подпись между версиями не меняется.
4. На Xiaomi/HyperOS и Samsung разрешите приложению работу в фоне без ограничений
   (настройки батареи и «Автозапуск»), иначе система может остановить воспроизведение.

Контрольная сумма — файл `SHA256SUMS` в том же релизе:

```bash
shasum -a 256 -c SHA256SUMS
```

## Приватность

Телеметрии, аналитики и crash-репортинга нет. Приложение не передаёт данных о вас
и о том, что вы слушаете, никому, кроме открытого вами сайта.
